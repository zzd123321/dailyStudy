# 你的学习记录

macOS 终端：

```bash
cp docs/learning-log-template.md notes/day-001.md
```

首次完成后，按 [macOS 学习工作流](../docs/cross-platform-workflow.md) 提交并推送。如果使用多台 Mac，换电脑开始前先拉取。
